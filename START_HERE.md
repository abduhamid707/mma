# USTOZ MMA CRM

Sodda, o‘zbekcha, desktop-first MMA klub boshqaruvi prototipi.

## Ishga tushirish
`index.html` faylini brauzerda oching. Qo‘shimcha paket o‘rnatish shart emas.

## Sahifalar
Dashboard; O‘quvchilar va profil; Abonementlar; To‘lovlar; Davomat; Hisobotlar; Sozlamalar.

## Ogohlantirish
Hozircha ma’lumotlar faqat brauzer localStorage'ida saqlanadi. Bu demo/prototip, production emas! Brauzer ma’lumotlari o‘chsa yozuvlar ham yo‘qolishi mumkin. Sozlamalarda JSON zaxira nusxasini muntazam yuklab oling. Real o‘quvchilar va moliyaviy ma’lumotlardan oldin server bazasi, login, rollar, zaxira va xavfsizlik kerak.

## Keyingi bosqich
PostgreSQL + API, admin autentifikatsiyasi, audit jurnali, server-side backup, testlar va deploy.
